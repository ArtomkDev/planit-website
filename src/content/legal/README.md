# Редагування юридичних документів

Чотири `.mdx`-файли в цій папці — єдине джерело тексту для юридичних
сторінок сайту:

- `privacy.mdx`
- `terms.mdx`
- `cookies.mdx`
- `delete.mdx`

Щоб змінити документ, відредагуйте текст у відповідному файлі. Next.js
автоматично прочитає його під час розробки або збірки та сформує абзаци,
списки, посилання, інформаційні блоки, definition lists і таблиці. Окрему
копію тексту в React або TypeScript оновлювати не потрібно.

Блок `legalMetadata` на початку файлу керує назвою сторінки, назвою в
боковій навігації, коротким описом, датою набрання чинності та версією.
Під час редагування форматованих блоків зберігайте семантичні теги навколо
тексту. Внутрішні посилання на сусідні документи мають вигляд `./privacy`,
`./terms`, `./cookies` і `./delete`.

Скрипт `scripts/import-legal-html.mjs` призначений лише для повторного
імпорту повних HTML-джерел. Він перезаписує всі чотири `.mdx`-файли й перед
записом перевіряє видимий текст та структуру блоків. Запуск:

```powershell
node scripts/import-legal-html.mjs "D:\path\to\legal-hosting"
```
