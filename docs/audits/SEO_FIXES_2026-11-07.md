# SEO-виправлення — 07.11.2026

Продовження [пошукового аудиту 25.10.2026](SEARCH_AUDIT_2026-10-25.md). Перевірено весь статичний експорт (15 індексованих сторінок, uk/en), метадані, hreflang, sitemap, robots, structured data і поведінку кореня `/`.

## Знайдені проблеми

| Проблема | Наслідок |
| --- | --- |
| Meta description юридичних сторінок брався з поля `summary` синхронізованих документів — це підзаголовок («Privacy at a glance», «Важливе коротко»), а не опис | 10 із 15 сторінок мали сніпети по 15–56 символів без змісту |
| Корінь `/` (x-default) виконував JS-перехід для всіх, зокрема для Googlebot (`en-US`) | Google рендерив корінь як `/en`; у звіті кореня видно заявлений canonical `/en`. hreflang x-default фактично вказував на сторінку з перенаправленням |
| `<noscript><meta http-equiv="refresh" content="0;url=/uk">` у корені | Роботи без JS (зокрема Bing) могли сприймати корінь як миттєвий redirect на `/uk` |
| Службові `/{locale}/auth/action` успадковували canonical і hreflang головної | Суперечливі сигнали: `noindex` + canonical на іншу сторінку |
| Внутрішні сторінки не мали `x-default` | Немає явної мовної версії для мов поза uk/en |
| Корінь не мав `og:locale`, розмірів і alt зображення; українська сторінка мала англійське OG-зображення | Гірші прев’ю в соцмережах і месенджерах |
| Немає `max-image-preview:large` / `max-snippet:-1` | Google може показувати лише мініатюри та обрізані сніпети |
| Structured data лише WebSite + SoftwareApplication | Немає хлібних крихт, WebPage з датою оновлення, FAQPage |

## Що змінено

- **Описи юридичних сторінок** — окремі SEO-описи 129–147 символів обома мовами в `SEO.<kind>.description` (`src/i18n/locales/*.json`), складені за змістом документів. Синхронізовані документи не змінено.
- **Корінь** — інлайн-скрипт не перенаправляє названих пошукових і соціальних роботів (`crawlerUserAgentPattern` у `src/lib/locale-redirect.ts`). Звичайні відвідувачі, як і раніше, автоматично переходять на збережену мову або мову браузера. Роботи бачать той самий HTML, що й відвідувач без JavaScript: сторінку вибору мови з посиланнями. `noscript` meta refresh прибрано; без JS залишаються видимі посилання на обидві мови.
- **Спільні SEO-хелпери** (`src/lib/seo.ts`): `INDEXABLE_ROBOTS`, `PRIVATE_ROBOTS`, `localeAlternates()` (x-default: корінь для головних, українська версія — для внутрішніх, як і fallback перенаправлення), `breadcrumbJsonLd()`, `webPageJsonLd()`. Компонент `JsonLd` безпечно серіалізує розмітку.
- **Structured data**: `FAQPage` на головних (дослівно з видимого FAQ), `WebPage` + `BreadcrumbList` на інструкції та юридичних сторінках, `dateModified` з дати документа. SoftwareApplication отримав `installUrl`, `alternateName`, `isAccessibleForFree`, `publisher`.
- **Службові сторінки** auth action: без canonical, hreflang і OpenGraph, лише `noindex, nofollow`.
- **Перемикач мови** в шапці має `hreflang` цільової мови.
- **Валідатор експорту** (`scripts/lib/site-seo.mjs`) тепер зупиняє збірку, якщо title довший за 70 символів, description коротший за 70 або довший за 170, або x-default відсутній чи вказує не туди.

## Перевірки

`tsc --noEmit`, `eslint`, **69/69** unit tests, production build з SEO-валідацією (15 сторінок), **12/12** export tests. Виведені теги звірено в `out/`.

Graphify не оновлено: локальний `graphify.ps1` завершився помилкою `uv trampoline failed to canonicalize script path`.

## Не змінено свідомо

- **H1 головної** — слоган «Менше хаосу. Більше планів.» залишено за прямим рішенням користувача від 24.10.2026 (DESIGN.md). Ключові слова є в title, description, бейджі та першому абзаці.
- **Тіла юридичних документів** надалі завантажує клієнтський читач; у початковому HTML є заголовок і оболонка. Google рендерить JavaScript, тож це не блокує індексацію, але попередній рендер MDX у HTML під час збірки ще більше посилив би ці сторінки.
- Дати `lastmod` для головних не додано, щоб у sitemap не потрапила штучна дата збірки.
